# Spotter Route Planner

## Features
- Dynamic city-based route planning
- Distance calculation using Geopy
- Driver HOS tracking
- Fuel stop estimation
- Interactive route map
- ELD logs dashboard
- Real-time route summary

## Tech Stack
- React.js
- Django REST Framework
- Geopy
- React Leaflet
- OpenStreetMap

## How It Works
1. User enters trip details.
2. React sends data to Django API.
3. Backend calculates distance, duration, fuel stops and HOS status.
4. Results are displayed on dashboard and map.
